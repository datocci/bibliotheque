# RÉUTILISATION ÉDITORIALE D'UN SHOOTING

Tu disposes maintenant de la fiche documentaire complète d'une publication.

Ta mission n'est plus d'étudier cette publication.

Ta mission est d'étudier **la vie éditoriale de la séance photographique principale**.

Cette rubrique sera ajoutée à la fiche existante.

Elle doit donc uniquement produire le contenu de cette rubrique.

══════════════════════════════════════
OBJECTIF
══════════════════════════════════════

Déterminer si tout ou partie du shooting a été réutilisé dans d'autres supports.

L'objectif n'est pas d'énumérer des produits.

L'objectif est de reconstituer le parcours éditorial d'une même séance photographique.

Le lecteur doit comprendre :

• où la séance est réapparue ;

• quels supports proposent des photographies différentes ;

• quels bonus utilisent cette séance ;

• quels produits dérivés en sont issus.

MÉTHODE
══════════════════════════════════════

Ne jamais partir du nom de la publication uniquement.

Chercher également :

• les costumes ;

• les coiffures ;

• les accessoires ;

• les décors ;

• les poses ;

• les crédits photographiques ;

• les titres de dossiers ;

• les scans ;

• les blogs japonais ;

• les archives Hatena ;

• Ameblo ;

• FC2 ;

• Stage48 ;

• Hello! Online ;

• JPHiP ;

• forums chinois ;

• forums taïwanais.

Comparer les photographies lorsqu'elles sont disponibles.

Déterminer si les images sont :

• identiques ;

• recadrées ;

• des prises alternatives ;

• ou simplement de la même séance.

══════════════════════════════════════
RÈGLES
══════════════════════════════════════

Ne jamais présenter une hypothèse comme un fait.

Distinguer clairement :

• confirmé ;

• probable ;

• hypothétique.

Privilégier les sources indépendantes.

Si plusieurs éléments convergent mais qu'aucune preuve absolue n'existe, employer un vocabulaire prudent.

══════════════════════════════════════
RÉDACTION
══════════════════════════════════════

Produire uniquement la rubrique Markdown.

La rubrique doit être concise mais riche.

Pour chaque support identifié, expliquer :

• ce qu'il apporte ;

• pourquoi il est intéressant ;

• en quoi il complète la publication principale.

Ne pas raconter l'histoire complète des autres publications.

Toujours recentrer le texte sur la publication étudiée.

══════════════════════════════════════
CONCLUSION
══════════════════════════════════════

Terminer par un court état des recherches.

Préciser :

• ce qui est confirmé ;

• ce qui reste probable ;

• quelles pistes restent ouvertes.

Le lecteur doit comprendre le degré d'avancement de la recherche documentaire.
